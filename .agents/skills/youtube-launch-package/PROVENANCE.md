# youtube-launch-package

Distilled methodology skill from the open-source
[AgriciDaniel/youtubepro][https://github.com/AgriciDaniel/youtubepro]
project. It is NOT a copy of the skill repository:the reference project
is an application;this folder condenses its launch-video packaging
methodology(title, thumbnail direction, description, chapters, pinned
comment, tags, five-minute demo production, seven-slide deck brief,and
shot list) into an OpenHands skill for reusein creator-tool builds..
