# youtubepro-hardening

Distilled methodology skill from the open-source
[AgriciDaniel/youtubepro][https://github.com/AgriciDaniel/youtubepro] project.
It is NOT a copy of the skill repository:the reference project is an
application;this folder condenses its app-engineering hardening contract
(local-first privacy, snapshot/evidence identity, strict validation, rate
limiting, CI verification door,) into an OpenHands skill for auditing and hardening
creator-tool / local-first AI SaaS builds..
