# youtube-script-writer

Distilled methodology skill from the open-source
[AgriciDaniel/youtubepro][https://github.com/AgriciDaniel/youtubepro]
project. It is NOT a copy of the skill repository:the reference project
is an application;this folder condenses its script-generation prompt
contracts and validation rules into an OpenHands skill for reuse in creator-tool
builds..
